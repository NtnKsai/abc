# ABC FLASHCARDS

เว็บแอปฝึกจดจำตัวอักษรภาษาอังกฤษ A–Z สำหรับใช้ในห้องเรียน พัฒนาโดย NtnKsai โรงเรียนวัดแคทราย (บุญประชาสรรค์)

## ไฟล์ในโปรเจกต์

- `index.html` — โครงสร้างเว็บไซต์และหน้าจอทั้งหมด
- `style.css` — รูปแบบหน้าตาและ Responsive UI
- `data.js` — ข้อมูล A–Z และคำศัพท์ 26 คำ
- `app.js` — ระบบแฟลชการ์ด สุ่ม แบบทดสอบ เสียง และการตั้งค่า
- `assets/images/` — ภาพประกอบ SVG ในเครื่อง 26 ภาพ
- `assets/icons/app-icon.svg` — ไอคอนเว็บแอป
- `manifest.webmanifest` และ `sw.js` — รองรับติดตั้งเป็นเว็บแอปและแคชไฟล์เพื่อใช้งานออฟไลน์

## วิธีเปิดใช้งาน

1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome หรือ Edge
3. เลือกโหมดการเรียนรู้หรือกิจกรรมจากหน้าแรก

หมายเหตุ: เสียงอ่านใช้ Web Speech API ของเบราว์เซอร์ ซึ่งความพร้อมของเสียงภาษาอังกฤษขึ้นอยู่กับอุปกรณ์และเสียงที่ติดตั้งไว้ หากต้องการแคชออฟไลน์ให้ครบ แนะนำเปิดผ่าน HTTPS หรือ localhost อย่างน้อยหนึ่งครั้งก่อนใช้งานแบบออฟไลน์

## วิธีนำขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดภายใน `abc-flashcards` ไปไว้ที่รากของ Repository (ไม่จำเป็นต้องอัปโหลดโฟลเดอร์ `abc-flashcards` ซ้อนอีกชั้น)
3. เข้า **Settings → Pages**
4. ในส่วน **Build and deployment** เลือก **Deploy from a branch**
5. เลือก Branch `main` และ Folder `/ (root)` แล้วกด Save
6. รอให้ GitHub Pages เผยแพร่ แล้วเปิด URL ที่ GitHub แสดง

## ฟังก์ชันที่มี

- โหมด A–Z + a–z, A–Z, a–z และ Picture Mode
- ภาพประกอบและคำศัพท์ภาษาอังกฤษครบ 26 ตัว
- Previous / Next / Random แบบไม่ซ้ำภายในรอบ / Auto Play 3 ความเร็ว
- Hide & Reveal พร้อมประเมินว่าตอบถูกหรือผิด
- Multiple Choice Quiz แบบ 4 ตัวเลือก พร้อมเสียงคำใบ้และสรุปคะแนน
- อ่านชื่อตัวอักษรและคำศัพท์ด้วยเสียงภาษาอังกฤษผ่าน Web Speech API
- Full Screen Presentation และคีย์ลัด ←, →, Space, F, ESC
- ตั้งค่าเสียง คำศัพท์ จำนวนข้อ และสีพื้นหลัง
- Responsive สำหรับ Desktop, Tablet และ Mobile
- Service Worker สำหรับแคชไฟล์เพื่อใช้งานออฟไลน์หลังโหลดครั้งแรก

## คีย์ลัดในหน้า Flashcard

- `←` ย้อนกลับ
- `→` ถัดไป
- `Space` สุ่มตัวอักษร
- `F` เข้า/ออกโหมดเต็มจอ
- `ESC` ออกจาก Full Screen (เป็นพฤติกรรมมาตรฐานของเบราว์เซอร์)

## หมายเหตุ

เว็บไซต์ไม่ใช้ Backend หรือฐานข้อมูล คะแนนแบบทดสอบเป็นคะแนนของรอบปัจจุบัน ไม่ได้จัดเก็บประวัตินักเรียนหรือส่งข้อมูลออกไปภายนอก
